Lanternlight — Spot the Difference: a complete spot-the-difference game in static files. Two near-identical pictures side by side, six to ten fair differences per scene with rising difficulty, three original scenes (Harbour at Noon, Lantern Festival, Autumn Garden), found markers with a satisfying ring, hints, a countdown you can feel, combo scoring and a victory screen. Click a difference in either picture — keyboard: H hint, P pause, R restart, 1/2/3 scenes.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome and play. No network requests, no build step.
